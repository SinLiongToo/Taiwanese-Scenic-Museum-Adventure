# 🌏 景點博物館四界行 — 台灣景點台語互動教學 WebApp

這是一個專為初學者與兒童設計的**台灣景點台語學習互動網頁**，以台灣各地知名景點、博物館、自然地標與離島為主題。透過互動地圖、詞彙牆與台語聽力挑戰，讓學習台語變得無比有趣且實用！

---

## 🌟 核心功能特色

### 1. 景點探索 (Explore Places)
- 收錄 **120 個台灣代表性景點**，涵蓋 45 間國家級與代表性博物館、知名歷史古蹟，以及**全台 29 處二二八紀念公園與紀念碑**（北至基隆、南至屏東、東至宜花東、離島至綠島）。
- 每個景點均附帶英文名稱、台語白話字（台羅）拼音、教育性英文簡介、台語關鍵詞彙。
- 點擊語音按鈕即可聆聽景點名稱的台語發音。

### 2. 台灣互動地圖 (Interactive Map)
- 採用 **Leaflet.js + 內政部國土測繪中心 (NLSC 台灣通用電子地圖)** 官方圖資（附 Esri Topo 地形圖圖層切換），100% 正體中文標註、全台各縣市鄉鎮精準地形，零 API Key 需求，永久開放免費且不被封鎖。
- 所有 120 個景點以精確 GPS 座標（lat/lng）定位，並提供「🕊️ 二二八紀念 (29)」專屬快速聚焦按鈕。
- 點擊地圖釘出現 **popup 卡片**：顯示景點名、台語拼音、關鍵詞彙、簡介，以及「播放台語發音」按鈕。
- **不跳頁**：所有互動在地圖頁內完成。
- 地圖釘依景點類型使用不同顏色（博物館=青綠、火山=橘、離島=粉紅……）。

### 3. 台語詞彙牆 (Vocabulary Wall)
- 精選 **211 個詞彙對照**：由 91 個基礎自然、文化、博物館、古蹟、人權和平詞彙，以及 120 個景點地點名稱動態組成。
- 每張卡片附帶 Emoji、中文、台羅拼音與英文翻譯。
- 支援 **七大分類篩選**：全部、陸地、水域、自然、博物館、文化、地點 (新增)。地點更支援**按縣市過濾**，並提供**互動式縣市統計分佈面板**。
- 支援 **詞彙檔案匯出**：網頁介面中提供一鍵「匯出 JSON」與「匯出 Markdown」功能，隨時下載學習清單。
- 點擊卡片即播放該詞彙的台語發音。

### 4. 台語聽力挑戰 (Quiz Challenge)
- 共 **8 題隨機聽力題**，播放景點的台語名稱，在 15 秒內從 4 個選項中選出正確答案。
- 答對 6 題以上即為通過，獲得「台語景點達人認證」。
- 含倒數計時條、分數追蹤與即時回饋（含台語拼音對照）。

## 🔊 台語語音說明：本調 vs 連音變調

### 台語的七個聲調（本調）

| 調號 | 名稱 | 特色 |
|------|------|------|
| 1 | 陰平 | 高平 |
| 2 | 陰上 | 低降 |
| 3 | 陰去 | 中低 |
| 4 | 陰入 | 短促（-p/-t/-k/-h 結尾）|
| 5 | 陽平 | 中升 |
| 7 | 陽去 | 中平 |
| 8 | 陽入 | 短促（-p/-t/-k/-h 結尾）|

> 注意：台語傳統上有「第六調」，但在台南腔等主要腔調中，第六調合併入第二調，故實際上只有七個聲調。

### 連音變調（Tone Sandhi）

台語具有嚴格的**連音變調規則**：多音節詞中，除最後一個音節保持本調，其餘每個音節均需變調。

| 本調 | → 變調 |
|------|--------|
| 1 | → **7** |
| 2 | → **1** |
| 3 | → **2** |
| 4 | → **8** |
| 5 | → **7** |
| 7 | → **3** |
| 8 | → **3** |

**範例：「日月潭」**

| 音節 | 本調 | 前字變調 | 說明 |
|------|------|----------|------|
| 日 jit | 8（陽入）| → **3** | 非最後字，套用變調 |
| 月 guat | 8（陽入）| → **3** | 非最後字，套用變調 |
| 潭 tham | 5（陽平）| 保持 **5** | 最後一字，不變調 |

所以母語者說的是 `jit3-guat3-tham5`，而非 `jit8-guat8-tham5`。

### ✅ 已完整整合：道地連音變調引擎 (Tone Sandhi Engine)

專案現已完整內嵌專業級**台語連音變調轉換引擎**（參考與整合同作者專案 [Taiwanese Lô-má-jī Tone Sandhi Tool](file:///c:/Users/tu-hs/OneDrive/文件/2022_0308_MASA/2022-0708/Projects_antigravity/Taiwanese%20Lô-má-jī%20Tone%20Sandhi%20Tool) 之語音學演算法）：

- 🔄 **嚴格遵循教育部標準變調規律**：
  - 陰平 `1 ➔ 7` (高平➔中平)
  - 陰上 `2 ➔ 1` (高降➔高平)
  - 陰去 `3 ➔ 2` (低降➔高降)
  - 陰入 `4`：若以 `-h` 喉塞音結尾 `➔ 2`（且脫落 `-h`）；若以 `-p/-t/-k` 結尾 `➔ 8` (高入)
  - 陽平 `5 ➔ 7` (低升➔中平)
  - 陽去 `7 ➔ 3` (中平➔低降)
  - 陽入 `8`：若以 `-h` 喉塞音結尾 `➔ 3`（且脫落 `-h`）；若以 `-p/-t/-k` 結尾 `➔ 4` (低入)
- 🧩 **詞組與複合詞智慧分組 (Phrase Chunks & 2+2 Split)**：
  - 支援 4 字複合名詞的 `2+2` 兩兩變調（如「億載金城」`It-tāi (8+7) Kim-siânn (7+5)`）。
  - 支援長地名的自然節奏詞群分組（如「基隆二二八紀念碑」依 `[基隆] [二二八] [紀念碑]` 分段變調）。
- 🎚️ **一鍵切換開關**：
  - 頂端導航列提供 **`🗣️ 連音變調：開 / 關`** 快捷按鈕，學習者可自由切換聆聽「道地口語連音發音」或「字典查詢單字本調」。

## 🛠️ 技術架構與語音引擎

本專案為**純前端網頁應用程式**，採用 HTML5, Vanilla CSS 與原生 JavaScript 編寫，無須安裝額外後端依賴。所有代碼整合於單一 `index.html` 檔案中。

### 雙模台語語音引擎 (Dual-Mode TTS Engine)

1. **教育部台語真人發音（線上 Web Audio API 主引擎，遵循 `taiwanese-moe-audio` 規範）**
   - **KipSutian 鏡像版本同步**：連線至 [ChhoeTaigi KipSutianDataMirror](https://github.com/ChhoeTaigi/KipSutianDataMirror)，鎖定最新 active 版本 `20261019-0109`，解決上游目錄清理導致 404 之問題。
   - **Web Audio API 無縫連音 (Gapless Playback)**：消除傳統 HTML5 Audio 逐字播放時 100~300ms 突兀間隔，音節連續發聲宛如真人流利口語。
   - **自動靜音裁切 (Auto Silence Trimming)**：演算法動態分析音訊波形，自動去除辭典 MP3 錄音首尾空白段落（保留 ~15ms 緩衝防爆音），實現字音緊湊流暢銜接。
   - **記憶體解碼緩存 (AudioBuffer Cache)**：平行預先載入解碼並快取至記憶體，重複發音零延遲。
   - **道地連音變調 (Tone Sandhi Engine)**：整合教育部標準變調規則（`1➔7`, `2➔1`, `3➔2`, `4(-h)➔2`, `4(-ptk)➔8`, `5➔7`, `7➔3`, `8(-h)➔3`, `8(-ptk)➔4`）與 4 字 2+2 複合詞分割。
   - **變速播放**：支援 0.5x ~ 2.5x 多段速度平滑變速（維持原音高）。

2. **Web Speech API 擬真離線備援**
   - 優先搜尋瀏覽器內建之台語原生音色（`nan` / `Mei-Jia` / `Taiwanese`）。
   - 若僅有華語音色，自動啟動 `twHomophones` 諧音擬真字典，將詞彙替換為最貼近台語發音之漢字諧音。
   - Header 即時顯示語音引擎狀態 Badge（🔊 實體台語 (連音變調) / 🔇 離線備援）。

### 地圖技術
- **Leaflet.js 1.9.4** + OpenStreetMap 底圖
- 所有景點以真實 GPS 座標定位（`lat`, `lng`）
- 自訂 `divIcon` 地圖釘（支援顏色分類、active 狀態高亮）
- Popup 卡片含語音播放按鈕
- Tab 切換時 lazy init（避免地圖 container 未顯示時初始化失敗）

### 其他技術特色
- **深色模式**：支援 Light / Dark 主題切換，設定儲存於 `localStorage`
- **語速調節**：0.5x ~ 1.5x 語速滑桿
- **響應式設計 (RWD)**：支援手機、平板與桌上型電腦
- **Glassmorphism 視覺設計**：玻璃擬物化卡片、漸層背景、微動態互動效果
